Warframe State Graph
====================

ゲーム内の依存関係グラフと自分の所持状態・目標を接続し、
「次の1手」を動的に再構成する非公式ツールです。

■ 使い方
warframe-state-graph.exe をダブルクリックしてください。
URLバーの無いウィンドウが自動で開きます。終了はそのウィンドウを閉じるだけです。

■ このフォルダについて
初回、何かを保存すると、このexeと同じ場所に data フォルダが自動的にできます。
そこにあなたの記録（ノードの達成状態・MOD構成・メモ等）が保存されます。
このフォルダ（exeとdataがまとめて入っているフォルダ）ごと扱ってください。
・バックアップ/コピーするときはフォルダごと
・デスクトップに置きたいときは、exe自体ではなく「ショートカット」を作ってください
　（exe自体を動かすと、置いていかれたdataフォルダとはぐれてしまいます）

■ アップデートの仕方
新しいバージョンが出たら、GitHubのReleasesページから最新のzipをダウンロードし、
中の warframe-state-graph.exe を、今このフォルダにある warframe-state-graph.exe に
上書きするだけで大丈夫です。data フォルダには触れなくて構いません
（記録はexeの中身ではなく、このフォルダ基準で保存されるため引き継がれます）。
心配な場合は、上書き前に data フォルダだけ別の場所にコピーしておくとより安全です。
https://github.com/MotimotiNotch/warframe-state-graph/releases

■ 初回起動時に「アクセスが拒否されました」等で弾かれる場合
このexeはコード署名なし（未署名バイナリ）です。ビルド直後やダウンロード直後に
セキュリティソフトのリアルタイムスキャンでファイルが一時的にロックされ、
起動に失敗することがあります。数秒〜数十秒待ってから再度実行すると
通常は解決します。改善しない場合はセキュリティソフトの検疫履歴を確認してください。

■ ネタバレについて
このツールはWarframeの公開データ（WFCD）をそのまま扱うため、クエスト名・前提関係や
特定の入手手段を持つ武器名など、まだプレイしていないコンテンツの名称が
画面に表示されることがあります。アプリの初回起動時にも同内容の案内が出ます。

■ 通信・データについて
・外部通信はWFCD・calamity-inc（いずれも公開Warframeデータプロジェクト）から
　アイテム/MOD/クエスト等のゲームデータを読み取り専用で取得するのみです。
　個人情報の送受信は行いません。
・達成状態・MOD構成・メモ等、入力した内容はすべてこのフォルダ内の data\*.json に
　保存されるだけで、外部には一切送信されません。
・不具合が発生した場合、原因調査のためこれらのJSONファイルの提出を
　お願いすることがあります（こちらから依頼した時のみ・任意提出）。
